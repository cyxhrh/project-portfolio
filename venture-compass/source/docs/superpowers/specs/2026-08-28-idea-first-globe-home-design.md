# 商业即想法：地球主页设计

## 目标

将现有的研究条件页改为产品主界面。用户不再先填写品类、预算、国家和平台，而是先用自然语言写下一个商业想法，并以“寻找商业机会”进入后续演示流程。

该页面只负责表达产品理念与收集想法，不接入后端，不生成真实分析结果。

## 体验定位

- 核心理念：商业即想法。
- 主文案：每一个想法，都值得走向世界。
- 受众：没有跨境电商经验、但有初步商业念头的普通用户。
- 视觉语言：白底、深色字、灰白互动地球、红色国家点位。它是一个克制的编辑式产品首页，不是聊天机器人界面，也不是传统表单页。
- 设计参数：变化度 6，动效 5，信息密度 2。

## 页面组成

1. 保留现有的开场动效，完成后显示主页。
2. 顶部仅保留商机罗盘品牌标识。语言切换继续存在于可访问性层，但不在本轮主视觉中展示。
3. 主标题置于地球上方居中：`每一个想法，都值得走向世界。`
4. 地球位于视窗中央，保持当前的可拖拽、自动旋转、国家红点与悬停暂停行为。
5. 输入组件浮于地球下半部前景，成为页面最显目的可操作元素：
   - 多行文本输入，可输入一段商业构想。
   - 默认提示：`写下你的商业想法，从这里开始。`
   - 示例文本仅作 placeholder，不预填内容：`例如：为经常出差的人做一款可折叠宠物饮水杯`
   - 唯一主按钮：`寻找商业机会`。
6. 不显示旧的品类、预算、货币、目标国家、平台、返回和语言切换 UI，也不显示额外说明段落。

## 交互与状态

### 初始状态

地球以现有速度 1.7 自动旋转；用户可拖拽浏览，悬停任意国家红点时暂停，离开后恢复。标题与输入框静态呈现，避免额外装饰性动效。

### 输入状态

输入框获得焦点时，仅增强边框与按钮可用状态。空输入时按钮禁用，按钮文案不变化。输入内容存于本地 React 状态，不发送网络请求。

### 提交演示

输入非空后点击“寻找商业机会”：

1. 保留用户输入内容，按钮进入短暂的提交反馈状态。
2. 地球上的预置红点依次出现一轮雷达波纹，表达想法向全球扩散。
3. 本轮不跳转、不展示结果页、不伪造 AI 产出。提交反馈结束后，按钮恢复可再次点击。

该动作是演示反馈，为后续接入真实 Agent 分析预留入口，而不是声称已完成分析。

## 组件边界

- `App`：继续管理开场状态、语言与后续统一状态；增加“想法文本”的提交回调，不恢复旧 researchInput 流程。
- `ResearchForm`：更名或重构为只处理 idea 输入与提交反馈的主页容器，负责标题、输入组件与 `CountryGlobe` 的层级布局。
- `CountryGlobe`：保持现有选国点位、旋转、悬停暂停和波纹能力；增加由外部提交事件触发的短暂全点波纹能力。地球不再承担用户筛选国家的业务含义。
- `app.css`：以单一浅色主题重组主页布局与输入组件样式；保留键盘焦点、可读 placeholder 与 reduced-motion 回退。

## 可访问性与异常处理

- 输入框有明确可访问名称，Enter 与点击按钮均可触发提交。
- 禁用按钮使用原生 `disabled`，不能仅依赖颜色。
- `prefers-reduced-motion` 下不执行自动旋转和提交波纹；提交仍有文本状态反馈。
- 地球加载失败时维持可见的输入与按钮；不能因为 3D 组件失败导致主页不能继续演示。

## 验收标准

1. 开场动效后只看见品牌、宣言标题、地球、想法输入框和主按钮。
2. 页面没有旧的条件筛选字段、说明文本、国家表单或结果页面入口。
3. 输入为空时不能提交；输入想法后可以点击“寻找商业机会”。
4. 点击后可见一次明确但不夸大分析结果的地球扩散反馈。
5. 地球原有的拖拽、自动旋转、红点悬停暂停与点选波纹不回退。
6. 现有中英文文案系统仍可提供本页对应文本，即使语言切换本轮不在主视觉展示。
7. 组件测试覆盖空输入、提交回调、演示反馈和 reduced-motion 基本分支。

## 非目标

- 不接入后端、爬虫、LLM 或真实市场数据。
- 不恢复推荐、数据分析加载或证据抽屉页面。
- 不把地球重新作为国家筛选的可见表单。
