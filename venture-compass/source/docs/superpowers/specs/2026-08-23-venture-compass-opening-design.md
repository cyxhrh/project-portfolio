# Venture Compass 开场动效设计

## 目标

每次用户打开网站时，以一个短暂、可跳过的开场建立品牌印象，并在进入探索页前说明产品价值：Venture Compass 帮助用户用数据找到值得验证的跨境商品机会。

## 范围

- 每次页面初次加载都播放一次。
- 使用纯黑背景和纯白字标，不使用绿色或其他强调色。
- 使用既定的英文纯字标 `Venture Compass`。
- 开场完成后进入首页探索页。
- 不增加登录、持久化的“已看过”状态、音效或加载伪进度。

## 视觉与文案

- 背景：`#000000`。
- 图形与文字：`#FFFFFF`。
- 字标：`Venture Compass`。
- 说明文案：`用数据，找到值得验证的跨境商品机会`。
- 整体不使用图标、渐变、阴影或装饰性纹理。

## 动画时间线

| 时间 | 状态 |
| --- | --- |
| 0.0–0.5 秒 | 屏幕为纯黑，中央显现极小白点。 |
| 0.5–1.2 秒 | 两条极细白线从白点向外延展，再向内聚焦。 |
| 1.2–1.6 秒 | 线条消隐，白色字标淡入。 |
| 1.6–2.5 秒 | 字标保持，中文说明在下方淡入。 |
| 2.5–2.8 秒 | 所有元素平滑淡出，首页探索页显现。 |

总时长为 2.8 秒。缓动应平稳、克制，不使用弹跳、旋转或强烈闪烁。

## 交互与无障碍

- 任意点击或按 `Escape`，立即结束开场并进入探索页。
- `prefers-reduced-motion: reduce` 生效时，不播放点和线条动效：字标与说明同时静态出现 0.6 秒，然后进入首页。
- 开场容器应有可访问标签；不自动播放音频，不抢占键盘焦点。

## 实现边界

- 它是当前单页前端启动时的独立覆盖层，退出后从 DOM 移除，避免遮挡首页交互。
- 使用 CSS 关键帧或现有前端动效方案实现，不能把动画导出为视频或 GIF。
- 字标使用 `design/logo-english-wordmark-a.svg` 或等效的英文文本渲染；不重新使用不稳定的生成式中文字形。

## 验收标准

1. 正常动效在约 2.8 秒后自动进入探索页。
2. 点击任意位置和按 `Escape` 都能立即进入探索页。
3. 减少动态效果下不播放点线动画，并在约 0.6 秒后进入探索页。
4. 画面只有黑、白两色，显示英文 Logo 与指定中文说明。
5. 开场结束后不能阻止首页的滚动、点击或键盘操作。
