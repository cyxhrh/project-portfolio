# 商机罗盘 Venture Compass - 前端设计规格

## 1. 目标与边界

商机罗盘帮助跨境电商新手从兴趣方向出发，填写品类、预算、国家和平台后，获得三个可比较的商品机会方向及其可追溯证据。

第一版是桌面端黑客松演示模板。它包含完整的前端流程和可替换 mock 数据，不实现登录、订单、供应链、48 小时验证计划或真实评分算法。后端后续负责爬取、Agent 分析和实时结果。

## 2. 体验主线

`横向探索商业方向 -> 填写研究条件 -> 观看 Agent 研究 -> 横向比较 3 个商品机会 -> 查看站内证据`

横向浏览只帮助用户确定兴趣品类，不能替代数据驱动的商品推荐。用户选择品类后仍需补全预算、国家和平台。

## 3. 视觉语言

参考 Jason Bradley 的沉浸式横向视觉浏览：全屏内容主体、极简导航、底部缩略轨道和低噪声文字。转译后不使用作品集文案或静态影集，而用它建立“探索商业方向”的感觉。

- 主题：全站深石墨背景，不切换为浅色分区。
- 强调色：单一低饱和青绿色，用于选择状态、重点数据与主按钮。
- 字体：中文优先使用 Noto Sans SC，英文使用 Geist 或同等无衬线字体。
- 布局：桌面 1440px 投屏优先。每个横向场景占一个主要视窗。
- 动效：中等强度，仅用于切换、进度和抽屉状态。支持减少动态效果。
- 素材：所有真实图片在第一版使用带说明的占位符，不把生成的示意图伪装为市场证据。

## 4. 页面与模块

### 4.1 探索页 `/`

1. 顶部导航
   - 品牌：商机罗盘 Venture Compass。
   - 语言：中文 / English，默认中文。
   - 操作：打开关于产品的简短说明。

2. 横向商业方向画廊
   - 标题：`从一个你愿意投入的方向开始`。
   - 文案：`先选择感兴趣的品类。我们再用市场、预算和平台条件缩小机会范围。`
   - 内容：服装与表达、美妆与护理、家居与生活、宠物与陪伴、户外与兴趣。
   - 交互：滚轮、键盘方向键和左右按钮切换全屏场景；点击底部缩略图跳转。
   - 每个场景：品类标题、中英副标题、简短兴趣提示、选择此方向按钮。
   - 素材占位符：`[首页主视觉：代表当前品类氛围的高质量横向图，不能是产品数据截图]`。
   - 数码电子场景例外：使用提供的 `电子数码.mp4` 作为静音、循环、内联播放的背景视频。视频覆盖整个场景，添加深色遮罩，并保持中性的消费电子表达。

3. 底部缩略轨道
   - 显示九个品类场景缩略图。
   - 高亮当前场景，点击后切换场景。
   - 素材占位符：`[品类缩略图：九张统一色调、可识别但不过度具象的方向图]`。
   - 视觉交互：轨道是低高度的半透明胶片履带，不显示左右箭头或分页点。中心固定一个不移动的选框，缩略图在其下方横向循环移动；当前缩略图在选框内保持清晰高亮，其余缩略图统一使用半透明磨砂遮罩。

### 4.2 研究条件页 `/research`

1. 上下文提示
   - 标题：`为 {category} 建立研究条件`。
   - 文案：`这些约束帮助 Agent 判断什么方向更适合你现在开始。`

2. 条件表单
   - 意向品类：继承探索页选择，可返回修改。
   - 预算：货币与金额输入。
   - 目标国家：可搜索的国家选择器。
   - 目标平台：TikTok Shop、Amazon、Shopee 等选项。
   - 示例预填：服装与表达、¥5,000、美国、TikTok Shop。
   - 交互：必填校验，提交后进入研究状态。

3. 信息边界提示
   - 文案：`结果是值得验证的方向，不代表收益保证。`

### 4.3 Agent 研究页 `/researching`

1. 研究状态主视图
   - 标题：`正在为美国 TikTok Shop 寻找机会`。
   - 文案：`Agent 正在整理可用于判断的市场信号。`
   - 阶段：分析趋势、比对竞品、评估预算适配、整理证据。
   - 交互：阶段按时间推进；完成后自动或手动进入结果页。
   - 素材占位符：`[研究过程视觉：抽象数据采集、市场信号或网络节点动画，不得使用假图表冒充真实数据]`。

2. 状态分支
   - 加载：对应布局的骨架屏。
   - 数据不足：说明覆盖不足并允许返回修改条件。
   - 错误：显示重新研究按钮与保持当前输入的返回入口。

### 4.4 机会结果页 `/opportunities`

1. 结果总览
   - 标题：`为你筛出的 3 个商品方向`。
   - 文案：`基于 {category}、{budget}、{country} 和 {platform} 的当前研究结果。`
   - 交互：编辑条件并重新研究。

2. 横向候选商品展示
   - 显示三个候选商品方向，一个为主要推荐，另两个为替代方向。
   - 每屏包含：方向名称、机会评分、核心理由、预算适配、主要风险、查看数据依据按钮。
   - 交互：箭头、键盘方向键和底部候选轨道切换；保留当前选择状态。
   - 素材占位符：`[候选商品视觉：方向氛围图或真实商品集，不得写成数据证据]`。

3. 底部候选比较轨道
   - 始终显示三项的名称、总分、预算适配和风险摘要。
   - 用文本和图标完成比较，不使用大面积填充进度条。

### 4.5 证据抽屉

1. 触发与结构
   - 从当前结果页右侧滑出，不跳转外部页面。
   - 标题：`{opportunity} 的数据依据`。
   - 分区：趋势、竞品、价格、评论痛点、采集信息。

2. 证据项
   - 每项显示：结论摘要、指标或摘录、数据源、采集时间和原始链接。
   - 交互：来源链接新标签打开；关闭后回到原候选方向。
   - 数据状态：没有某类证据时明确写数据缺口。

## 5. 前端数据契约

页面以 mock 数据启动，数据模型与后端解耦。前端至少需要：

- `ResearchInput`：category、budget、currency、country、platform。
- `ResearchProgress`：stage、status、message。
- `Opportunity`：id、name、score、reasons、budgetFit、risk、visualPlaceholder、evidence。
- `EvidenceItem`：type、summary、metric、sourceName、sourceUrl、collectedAt、coverageNote。

评分含义和取值由后端定义。前端只负责清晰展示、比较和证据追溯。

## 6. 技术与验收

- React + TypeScript + Vite。
- Fluent UI React 作为表单、抽屉、提示和可访问性基础；不使用其默认视觉皮肤。
- Tailwind 或 CSS variables 管理自定义深色主题与设计 tokens。
- 1440px 桌面演示必须完整可操作；不承诺第一版移动端体验。
- 中英语言文本集中管理，不把文案散落在组件中。
- 所有图片位置必须显示明确的中文素材说明。
- 包含加载、无数据和错误状态。
- 不得使用虚假来源、伪造精确市场数据或暗示收益保证。

## 7. 不在范围内

- 登录、账号体系、支付、订单、物流或供应链管理。
- 48 小时验证方案、后续数据追踪与机会复评。
- 真实爬虫、评分模型、AI LIVE AGENT 接入和生产级 API。
- 移动端优先适配。
