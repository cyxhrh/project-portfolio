# Video Knowledge Mapper v0.1 最终验收清单

生成日期：2026-06-24

## 1. 当前已完成能力

### 主功能：生成学习笔记

- 支持输入 B站链接。
- 支持输入抖音链接。
- 支持选择本地 MP4。
- 点击“生成学习笔记”后执行完整分析流程：
  - 获取视频内容
  - 生成转写结果
  - 调用 AI 笔记生成
  - 输出 Markdown 笔记
  - 输出 Mermaid 思维导图
  - 输出 XMind 文件
  - 输出复习卡片数据
  - 输出可复用结果目录

### 次级功能：重新生成笔记

- 支持选择已有结果目录。
- 读取已有结果目录中的视频信息和转写文本。
- 不重新下载视频。
- 不重新转写音频。
- 可重新生成 Markdown、XMind 和复习卡片数据。

### 高级功能：仅生成转写结果

- 放在“高级选项”中。
- 支持视频链接或本地 MP4。
- 只生成转写文本和结果目录。
- 不调用 AI 笔记生成。
- 不生成 Markdown、XMind 或复习卡片数据。

### 结果打开体验

- 生成学习笔记完成后，可打开 Markdown、XMind 和结果目录。
- 重新生成笔记完成后，可打开 Markdown、XMind 和结果目录。
- 仅生成转写结果完成后，可打开转写文本和结果目录。
- 文件不存在时提示：文件不存在，请重新生成。
- 目录不存在时提示：结果目录不存在，请重新生成。

### UI 文案和日志

- 主界面突出“生成学习笔记”。
- “重新生成笔记”作为次级功能。
- “仅生成转写结果”放入高级选项。
- UI 日志中已对技术词做用户化替换：
  - Artifact 目录 → 结果目录
  - transcript.txt → 转写文本
  - metadata.json → 视频信息
  - table_summary_json → 复习卡片
  - mindmap JSON → 思维导图数据
  - faster-whisper → 转写模型
  - DeepSeek → AI 笔记生成

## 2. 用户需要手动验收的步骤

### 验收 A：生成学习笔记

1. 打开 Video Knowledge Mapper。
2. 输入一个真实可访问的 B站或抖音链接。
3. 点击“生成学习笔记”。
4. 观察状态区域是否显示普通用户能理解的阶段。
5. 等待任务完成。
6. 检查是否显示结果打开按钮：
   - 打开 Markdown
   - 打开结果目录
   - 打开 XMind
7. 分别点击三个按钮，确认文件或目录能打开。

### 验收 B：重新生成笔记

1. 选择一个已有结果目录。
2. 点击“重新生成笔记”。
3. 确认日志没有出现重新下载或重新转写相关步骤。
4. 等待任务完成。
5. 点击“打开 Markdown”。
6. 点击“打开 XMind”。
7. 点击“打开结果目录”。

### 验收 C：仅生成转写结果

1. 展开“高级选项”。
2. 输入视频链接，或选择本地 MP4。
3. 点击“仅生成转写结果”。
4. 确认日志没有出现 AI 笔记生成步骤。
5. 等待任务完成。
6. 点击“打开转写文本”。
7. 点击“打开结果目录”。

### 验收 D：错误提示

1. 不输入链接，也不选择本地视频，直接点击“生成学习笔记”。
2. 确认提示：请先输入视频链接，或选择本地视频文件。
3. 不选择已有结果目录，直接点击“重新生成笔记”。
4. 确认提示：请先选择一个已有结果目录。
5. 选择缺少转写文本或视频信息的目录。
6. 确认提示能说明结果目录不完整。

## 4. 已知小问题

## 6. v0.1 版本边界

v0.1 是一个本地桌面工具版本，目标是让普通用户完成一个核心任务：

> 把视频变成可复习的学习笔记。

版本边界：

- 输入范围：B站链接、抖音链接、本地 MP4。
- 输出范围：Markdown、Mermaid、XMind、复习卡片数据、转写文本、结果目录。
- 使用方式：Windows 桌面 UI 为主，命令行入口保留。
- 运行环境：本地 Windows 环境。
- 外部依赖：视频平台访问能力、转写模型、本地系统默认打开程序、AI 笔记生成 API Key。

v0.1 不承诺：

- 所有视频链接都一定可解析。
- 所有长视频都能快速完成。
- 所有系统都已配置 XMind 默认打开方式。
- 自动修复缺失或失效的 cookies。
- 自动处理平台风控、登录、验证码或权限问题。

## 7. 下一版本建议

建议 v0.2 只做小步体验增强：

- 增加更清晰的四步阶段进度条：
  - 获取视频内容
  - 生成转写结果
  - 生成学习笔记
  - 完成
- 增加“复制 Markdown 路径”和“复制结果目录路径”。
- 增加 DeepSeek API Key 配置说明或配置入口。
- 在长视频处理中显示更明确的耗时提示。
- 对失败原因做更细分的普通用户提示。
- 增加最近结果列表，方便用户重新打开历史笔记。

不建议 v0.2 立刻扩大平台或接入新系统。优先把当前三条核心路径打磨稳定。
