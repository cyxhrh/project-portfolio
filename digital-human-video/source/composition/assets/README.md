# 素材接口（分享包未包含原始媒体）

本目录仅提供无个人信息的 `contact-placeholder.svg`。原始人像、声音、二维码和业务 B-roll 均未复制。此目录是源代码展示，尚不是可直接渲染的完整媒体工程。

若用自己的已授权素材复现，请按 `index.html` 的媒体时点准备下列文件：

| 文件 | 角色与时间要求 |
| --- | --- |
| `avatar.mp4` | 连续数字人口播主源；原工程时长 53.08 秒，同时提供完整音轨。 |
| `avatar-face.mp4` | 与主源对应的面部裁切；覆盖原片 15.30–41.40 秒，供左下人物窗口使用。 |
| `01-安防装备检测.mp4` | 第一项业务背景，覆盖 4.45 秒。 |
| `02-标识制作安装.mp4` | 第二项业务背景，覆盖 4.29 秒。 |
| `03-楼宇翻新维护-慢放.mp4` | 第三项业务背景，覆盖 4.79 秒。 |
| `05-生产设备-能力段慢放.mp4` | 能力清单背景，覆盖 8.90 秒。 |
| `07-企业定制场景-慢放.mp4` | 定制服务背景，覆盖 5.47 秒。 |
| `logo.png` | 自己有权使用的品牌标识；无需复用示例品牌。 |
| `contact-placeholder.svg` | 已提供的通用联系信息占位图。 |

替换人物、文案或语速后，需重新校准 `edl.json`、HTML 媒体时点及 `master.ass` 字幕，不能直接套用旧版秒数。HTML 负责画面与动效；原项目将 ASS 字幕作为最后一层合成。
