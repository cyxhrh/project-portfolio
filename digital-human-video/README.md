# 企业数字人视频｜从口播到可复用的制作流程

以企业介绍视频为实践案例，我把数字人口播、辅助画面、信息卡、中文字幕与成片核验串成一个可迭代的制作流程。我的工作重点是内容与镜头规划、工具衔接、动效和字幕组织，以及根据实际成片反馈迭代。

## 技术路径

| 环节 | 工具与方法 | 在这个项目中的作用 |
| --- | --- | --- |
| 需求、口播与分镜 | Codex + 项目文档 | 梳理企业介绍、锁定口播、定义视觉规则和分段计划 |
| 数字人口播 | HeyGen | 生成完整人物口播，以最终原片音频确定全片时间基准 |
| 辅助动态画面 | MiniMax H3 | 补充业务主题的 B-roll；本地脚本支持提交、轮询和下载任务 |
| 剪辑规划 | video-use 工作方法 | 先搭粗剪、找素材缺口，再组织人物、业务画面和字幕 |
| 信息呈现与动画 | HyperFrames + HTML/CSS + GSAP | 实现人物画中画、标题卡、能力清单与转场时间线 |
| 成片合成与检查 | FFmpeg / ffprobe、ASS 字幕 | 组合连续口播和视觉层，最后叠加字幕，检查输出参数和画面 |

这是一套借助现有生成服务和本地代码完成的制作流程；数字人模型、语音模型和视频模型由对应服务提供。目前已完成案例制作和局部脚本衔接，尚未形成从 Brief 到发布的一键全自动系统。

## 我如何做取舍

**先锁音频，再安排画面。** 口播稿最初按 60 秒规划，实际数字人原片约 53 秒，因此最终时间线跟随真实口播。人物说话保持连续，画面与信息卡按完整语句进入，避免为了镜头长度切断话语。

**先验证约 10 秒，再进入全片。** 先用短 Demo 检验人物、业务画面、字幕和轻量动效能否配合，再做全片粗剪和素材补齐。这样可以在渲染整片前发现信息过密、素材不足和画面遮挡的问题。

**让人物负责讲述，让画面帮助理解。** 身份介绍和价值观段使用全屏数字人；业务段切换为动态背景，保留左下角人物画中画。背景服务于主题，准确的中文信息由可编辑标题与字幕呈现。

**能力清单逐条增加。** 当口播连续提到设计团队、生产设备、工程技术人员时，三张卡片按语音顺序出现并保留，方便观众在段落结尾看到完整信息。

## 可用于报名的介绍

企业数字人视频制作是我将 AI 生成工具与代码化剪辑结合的一次项目实践。我负责口播与镜头规划、工具协作、动效和字幕组织，并根据样片反馈迭代。项目以 HeyGen 数字人口播为基础，用 MiniMax H3 补充辅助动态画面，通过 HyperFrames、GSAP 和 FFmpeg 完成可编辑信息卡、人物画中画、字幕与成片合成。已完成约 53 秒竖屏企业介绍视频，并整理技术路线、创作取舍、合成工程和任务脚本。
