# 技术路径：用真实口播驱动视频制作

本说明根据 2026-08-18 的数字人项目制作记录、V3 工程和 2026-08-19 的工作经验整理；描述的是这个案例实际采用的路线。

```mermaid
flowchart LR
    A[口播与视觉规划] --> B[HeyGen 完整口播]
    B --> C[按实际语音确定时间线]
    C --> D[约 10 秒 Demo 与全片粗剪]
    D --> E[MiniMax H3 辅助画面]
    E --> F[HyperFrames 与 GSAP 视觉合成]
    F --> G[FFmpeg 合成音频并叠加 ASS 字幕]
    G --> H[取帧检查与 ffprobe 参数核验]
```

## 输入与中间产物

输入包括企业介绍稿、数字人原片、视觉风格规则和对应业务素材。中间产物包括分段时间线、素材清单、短 Demo、字幕、HTML 合成页面和动效断言；成片是流程的最终输出。

项目使用 HeyGen 制作数字人口播。MiniMax H3 承担辅助动态画面的生成；保留的 Python 脚本体现了环境变量读取凭据、创建任务、轮询状态与下载结果的衔接。video-use 是剪辑组织的方法指导，HyperFrames 是 HTML 合成工程的执行工具，二者职责不同。

## 实际时间线

| 时间 | 主要画面 | 处理重点 |
| --- | --- | --- |
| 0.00–15.76 秒 | 全屏数字人、身份与公司名称 | 按口播顺序展示名称，保持连续人物表演 |
| 15.30–27.93 秒 | 三段业务主题辅助画面 | 人物改为画中画，标题和字幕占据独立区域 |
| 27.48–36.38 秒 | 团队与能力清单 | 三条能力按语音顺序出现并留存 |
| 35.93–41.40 秒 | 定制服务画面 | 延续人物画中画与业务说明 |
| 41.40–53.08 秒 | 回到全屏数字人 | 价值观与结尾信息 |

时间段存在重叠，是因为相邻业务背景采用约 0.45 秒的渐变交叠。字幕时间与最终口播对应，字幕位于视觉合成的最后一层。最终容器时长 53.098 秒与工程标记 53.08 秒略有差异。

## 可复用部分

1. 口播锁定后，以音频为基准维护镜头、标题和字幕时点。
2. 将准确的中文文字留在代码和字幕层，修改文字时不用重新生成业务背景。
3. 用素材清单对照时间线，明确每段素材的用途和时长。
4. 把模型调用脚本和本地合成工程分别保留，方便定位是素材问题还是合成问题。

## 已实现与下一步

已实现：短 Demo 迭代、完整企业介绍成片、模型任务脚本、HTML/GSAP 合成工程、ASS 字幕、时间线与素材记录。

下一步：统一项目参数、素材状态与版本管理，减少人工在生成平台和本地合成之间的切换；再验证第二个主题能否复用同一套结构。批量调度、统一错误恢复和一键发布仍属于后续工作。

分享代码没有附带原始人像、声音与完整业务素材，不能仅下载代码就重建同一人物的全片；保留工程用于展示方法和结构，复现需另备授权素材。
