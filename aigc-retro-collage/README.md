## 画面看点

- **人物与版式结合：** 群舞、近景与大幅字形交替出现，人物既在场景里表演，也成为拼贴构图的一部分。
- **统一的复古色调：** 米色、棕色服装与暖色混凝土空间相互呼应，黑白文字和局部红色形成视觉重点。
- **空间与纸面交错：** 撕纸边缘、网点纹理与倾斜的文字平面穿插在人物镜头之间，形成杂志页面与立体场景相互转换的效果。
